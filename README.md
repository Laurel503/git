我的 Git 学习与项目仓库：在这里练习 Git 版本管理，存放学习笔记和小项目。

## 仓库结构

| 目录/文件 | 用途 |
|---|---|
| `notes/` | Git 学习笔记 |
| `projects/` | 练习项目 |

> 目录还不存在，第一次往里放文件时创建即可。

## 常用命令备忘

```bash
git status              # 看哪些文件改了
git add 文件名           # 把文件加入暂存区（准备提交）
git commit -m "说明"     # 提交到本地仓库
git push                # 推送到 GitHub
git pull                # 从 GitHub 拉取最新内容
```
